      How to Use

      Split PDF

      Select a PDF or drag it onto the card to load page thumbnails.

      Click thumbnails to select pages — shift+click for a range. Drag selected pages in the strip below to reorder.

      Click a selected page to open the annotation preview. Double-click a selected page for full-screen annotation. All marks export into the output PDF.

      Or type pages like 1,1,3-5,7-2 or "all". Optionally set an output filename. Click Extract Pages to download.

      Annotating

      ✎ Pen and ◧ Highlighter: hold the mouse button and drag to draw. Adjust color and stroke width in the toolbar.

      T Text: click anywhere on the page to place text. With the ↖ pointer tool, drag text to move it, or double-click it to edit its content, color and size. ⌫ Eraser: click a mark or text to delete it.

      Merge PDFs

      Select or drag multiple PDFs onto the card. Each file shows a first-page preview and page count.

      Drag items or use ▲/▼ to reorder. Optionally set an output filename. Click Merge Files to download.

      Organize Pages

      Select a PDF to see all pages. Drag thumbnails to reorder them, click × to delete a page, then click Save PDF. Detect blank pages removes empty scanned pages in one click; Reset pages restores the original document.

      Rotate PDF

      Select a PDF, then use the ⟲ / ⟳ buttons under each page — or rotate all pages at once. Click Save PDF to download the rotated document.

      Add Page Numbers

      Select a PDF, choose position, format, starting number, font size and margin. The preview shows the first page exactly as it will export. Click Add Numbers to download.

      Sign PDF

      Select a PDF, then draw your signature on the pad (mouse or touch) or upload a signature image — a PNG with transparent background works best.

      Choose the page, set the signature width, and drag the signature overlay to position it. Click Apply Signature to download.

      Crop PDF

      Select a PDF and drag the frame (or its corners) over the area you want to keep — everything outside is removed. Auto-trim margins fits the frame to the visible content automatically. Leave "Apply to all pages" checked to crop every page with the same frame, or uncheck it to crop only the previewed page. Reset frame restores the full page.

      Images to PDF

      Select or drag JPG/PNG images onto the card. Reorder them by dragging, choose "Fit to image" or A4 page size, then click Create PDF.

      PDF to Images

      Select a PDF, pick an image quality, and click Convert to PNG. A single page downloads as PNG; multiple pages download together as a ZIP.

      Watermark PDF

      Select a PDF, type your watermark text, and adjust size, color, opacity, angle and layout. The preview shows exactly how it will look. Choose all pages or first page only, then click Add Watermark.

      Protect PDF

      Add password: select a PDF, enter and confirm a password, optionally restrict printing/copying, then click Protect PDF. Encryption is AES-256.

      Remove password: switch the mode, select the protected PDF, enter its current password, and click Remove Password.

      PDF to Text

      Select a PDF to extract its selectable text. Copy it to the clipboard or download a .txt file. Scanned image-only pages contain no selectable text — those yield empty output.

      Compress PDF

      Lossless re-compresses streams and removes redundancy without touching quality. Strong additionally re-encodes embedded JPEG images at the quality you choose (and downscales very large ones). The status shows the exact before/after sizes. Text and vectors stay sharp in both modes.

      Fill & Flatten Forms

      Select a PDF with fillable (AcroForm) fields. Text boxes, checkboxes, dropdowns and radio groups appear as normal inputs. Fill them, then Save PDF. With Flatten checked the fields become permanent page content; unchecked, the saved PDF stays fillable.

      The encryption engine downloads once on first use; your file and password are processed entirely on your device.

      Tips

      Drag files directly onto any card instead of using the file picker.

      The active Split/Merge card expands to full width; the collapsed card shrinks to a slim bar — click it to switch.

      Privacy

      No upload. Files never leave your device; all processing happens locally in your browser.
