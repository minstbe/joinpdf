How to Password Protect a PDF Without Uploading It (AES-256)

Published on 2026-11-10 · Add a strong AES-256 password or remove one you know — entirely in your browser. No file or password ever uploaded.

Password-protecting a PDF is the simplest way to keep a document private when you email it or share it on a drive. Most online tools make you upload the file first — which defeats the purpose for sensitive documents. This guide shows how to add a password entirely in your browser.

What kind of encryption?

The tool on joinpdf.top uses AES-256 (PDF revision 6), the strongest encryption the PDF format supports. It is the same standard used by desktop Acrobat. Older "40-bit RC4" protection found in some free tools can be broken quickly — avoid it.

Quick steps

  1. Open joinpdf.top and scroll to Protect PDF.
  2. Keep the mode on Add password and select your PDF.
  3. Enter a password and repeat it in the confirm field.
  4. Optionally uncheck Allow printing or Allow copying text to restrict what recipients can do.
  5. Click Protect PDF. The encrypted file downloads immediately.

The first use downloads a small encryption engine (qpdf compiled to WebAssembly). After that it is cached by your browser. Your file and your password are never transmitted anywhere.

User password vs owner password

PDF supports two passwords: a user password required to open the file, and an owner password that controls permissions. For everyday sharing, one strong password is enough — the tool sets both to the value you enter.

Removing a password later

Switch the mode to Remove password, select the protected file, and enter its current password. You get back a clean, unencrypted copy. This only works if you know the password — it is not a cracking tool.

Tips

  • Use a long passphrase rather than a short complex word.
  • Share the password through a different channel than the file (e.g., file by email, password by messenger).
  • Permission flags (no printing/copying) are enforced by honest viewers, not cryptographically — the open password is the real protection.
